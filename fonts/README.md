Self-hosted copies of Google Fonts so the app works offline:

- **Chakra Petch** (600, 700): brand and headings, shared ARTIN Studios look
- **Barlow** (400, 500, 600): interface text
- **Share Tech Mono** (400): numbers and labels
- **Yatra One** (400, Devanagari + Latin): Hindi names such as अनार and फुलझड़ी

All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
To refresh a font, download the `.woff2` for the subset from the Google Fonts CSS API
(`https://fonts.googleapis.com/css2?family=<Name>`) and update `css/fonts.css`.
